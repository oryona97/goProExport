# Organize both destinations by recording date

Both local and cloud destinations group original videos by their recording day, with each video directly inside its date folder, so videos from the same recording day remain grouped across save batches instead of by import or camera. Each chapter uses its own recording day in a chosen recording timezone, defaulting to the PC's timezone with an optional override; preserve that timezone with the batch, and use Unknown date for missing or invalid dates. Preserve original filenames, using a conflict subfolder as the exception to the flat daily layout when different originals share a filename.
